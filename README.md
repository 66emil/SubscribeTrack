# SubscribeTrack

Веб-приложение на Django для учёта личных подписок: какие сервисы оплачиваются, по какому тарифу, сколько это стоит и когда следующее списание.

## Возможности

- Каталог компаний, сгруппированных по категориям, с тарифными планами и ценами
- Учёт активных подписок пользователя: тариф, стоимость, период оплаты, дата следующего списания
- Статусы подписки — активна, приостановлена, отменена, истекла
- Периодичность оплаты: ежемесячно, ежеквартально, ежегодно
- Полный CRUD по категориям, компаниям и подпискам через веб-интерфейс
- Разграничение доступа: просмотр открыт всем, создание и редактирование — только авторизованным
- Стандартная админка Django
- Скрипт наполнения тестовыми данными

## Модель данных

**Category** — категория для группировки компаний (например, «Стриминг», «Облака»).

**Company** — сервис, предоставляющий подписки. Тарифы хранятся в `JSONField` в формате «название плана → цена», что позволяет держать произвольный набор тарифов без отдельной таблицы.

**Subscription** — активная подписка конкретного пользователя: ссылки на пользователя и компанию, выбранный тариф с зафиксированной ценой, период оплаты, статус, даты начала, следующего списания и окончания.

## Стек

Python, Django 5.2, SQLite, шаблоны Django.

## Установка

```bash
git clone https://github.com/66emil/SubscribeTrack.git
cd SubscribeTrack
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Миграции и суперпользователь:

```bash
python manage.py migrate
python manage.py createsuperuser
```

Тестовые данные (опционально):

```bash
python create_sample_data.py
```

Запуск:

```bash
python manage.py runserver
```

Приложение будет доступно на `http://127.0.0.1:8000/`, админка — на `/admin/`.

## Маршруты

| Путь | Назначение |
|---|---|
| `/` | Главная со сводкой по количеству категорий, компаний и активных подписок |
| `/categories/` | Список категорий, детальная страница, создание, редактирование, удаление |
| `/companies/` | То же для компаний |
| `/subscriptions/` | То же для подписок пользователя |

## Перед деплоем

Проект настроен под локальную разработку: `DEBUG = True`, пустой `ALLOWED_HOSTS`, SQLite и секретный ключ в `settings.py`. Для боевого окружения вынесите ключ в переменные окружения, отключите отладку, заполните `ALLOWED_HOSTS` и переведите базу на PostgreSQL. Локаль и таймзона сейчас `en-us` / `UTC` — при необходимости смените на `ru-ru` и нужный часовой пояс.
